Een website ontwikkelen

Bij het ontwikkelen van een website doorlopen we verschillende stappen. Sommige stappen bestaan uit meerdere onderdelen.

Werkwijze

    1. Analyseer de opdracht.

      Bepaal het doel van de website.
      Bepaal de gewenste inhoud.

    2. Bereid het project voor.

      Maak een projectmap.
      Maak het bestand index.html.

    3. Bouw de webpagina.

      Voeg de HTML-basisstructuur toe.
      Structureer de inhoud met passende elementen

    4. Test het resultaat.

      Open de pagina in de browser
      Valideer de HTML-code

Voer de hoofdstappen uit in de aangegeven volgorde
