Begrippenlijst webontwikkeling

Hieronder worden enkele belangrijke begrippen uit webontwikkeling verklaard.

Begrippen

Client

-Een programma dat bestanden of gegevens bij een server opvraagt.

Server

-Een computer of programma dat aanvragen verwerkt en antwoorden terugstuurt.

HTML

-Een taal waarmee de structuur en betekenis van webinhoud worden beschreven.

CSS

-Een taal waarmee de vormgeving van de webpagina wordt bepaald.

JavaScript

-Een programeertaal waarmee gedrag en interactie aan een webpagina worden toegevoegd

Deze begrippen vormen de basis van front-endontwikkeling
